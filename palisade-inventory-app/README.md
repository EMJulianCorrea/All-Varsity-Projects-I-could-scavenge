# Palisade Inventory App

Mobile inventory management application for Palisade Concrete Products.

Developed by IronGrid Technologies (Group 4) for INSY7315 WIL.

## Project Purpose

The purpose of this application is to help Palisade Concrete Products manage inventory, product categories, stock levels, and sales more efficiently by replacing the current spreadsheet-based approach with a mobile application.

## Core Features

- User login and registration
- Product categories
- Inventory management
- Add and edit products
- Record sales
- Automatic stock updates
- Sales history
- Search products
